# Excel Monthly Expense Tracker

A beginner-friendly Excel project created to practice basic spreadsheet skills and simple expense analysis.

## Version 1 - Basic Expense Analysis

The workbook contains 15 sample daily expenses with these columns:

- Date
- Category
- Description
- Amount

## Excel Concepts Practiced

- Data entry and table formatting
- Sorting and filtering
- SUM
- AVERAGE
- MAX
- MIN
- COUNTIF
- Basic summary calculations

## Workbook Summary

The workbook automatically calculates total expense, average expense, highest expense, lowest expense, and the number of Food entries.

## Learning Progress

This is intentionally a beginner-level Version 1 project. As my Excel skills improve, I can gradually add PivotTables, charts, category-wise analysis, and eventually a simple dashboard.
